[ STAGE 1: DETERMINISTIC GRAMMAR LEXER & RESIDUAL-STATE AST PARSER ]
--------------------------------------------------------------------------------
• Replaces: HiChunk's 4B-LLM segmentation (Lu et al., ACL 2026) & naive regexes.
• Input: Raw document string D (Markdown / ASCII / Formatted Text).
• Deterministic Mechanisms:
    1. Fixed-Width Lookbehind Boundary Compiler:
       - Configurable protected abbreviations (Dr., Corp., Inc., vs., etc.)
       - Roman numeral list protection: r'(?<=\b[ivxIVX]{1,5}\.)\s+'
       - Numbered list item protection: r'(?<=\b\d{1,2}\.)\s+'
       - Directional/bullet symbol lookaheads: '->', '=>', '•'
    2. Zero-Latency AST State Stack:
       - Deterministic Finite Automaton (DFA) over headings, Roman sections, indented clauses.
       - Maps every clause to an AST root-to-leaf path: e.g., [Doc > Chapter 4 > Section 4.2].
• Output Contract:
    - Syntactic Clause Sequence: List[Clause(text, byte_span, ast_path, symbol_id)].
• Invariant: Zero boundary fractures on Roman numerals, lists, or protected initials.


[ STAGE 2: DETERMINISTIC CENTERING STACK + LOCAL NEURAL MARGIN GATE ]
--------------------------------------------------------------------------------
• Replaces: Jang et al. (ACL 2025) destructive GPT-4o-mini text rewriting.
• Input: Syntactic Clause Sequence from Stage 1.
• Deterministic Mechanisms:
    1. 5-Tier Scope Stack:
       - Tier 1: Global Document Registry (Preamble / formal definitions).
       - Tier 2: Hierarchical AST Scope (Section Governors).
       - Tier 3: Discourse Focus Stack (LIFO push/pop for side topics).
       - Tier 4: Typed Backward Anchors ("such [Noun]", "the aforementioned [Noun]").
       - Tier 5: Canonical Citation Symbol Table (Explicit citations: Section X.Y, Footnote N).
    2. Strict Morphosyntactic Agreement Pre-Filter:
       - "It" / "Its" -> Singular + Inanimate/Corporate (ORG, PRODUCT, CONTRACT).
       - "He" / "She" -> Singular + Animate (PERSON).
       - "They" / "Their" -> Plural OR Collective ORG.
       - "This [Noun]" -> Lexical head-noun/hypernym match against preceding predicates.
    3. Hybrid Neural Tie-Breaker (Qwen3-Embedding-0.6B FP16):
       - Triggered ONLY when 2+ candidates survive deterministic morphosyntactic filtering.
       - Cloze + Predicate similarity gated by:
             Score >= 0.52 (MIN_CONFIDENCE_THRESHOLD)
             Margin = (Score_1 - Score_2) >= 0.05 (MIN_MARGIN_THRESHOLD)
• Output Contract:
    - Asymmetric Metadata Header: e.g., [Resolved Subject: 'It' -> Meridian Vault IP Holdings LLC]
• Invariant: Raw clause text is 100% bit-for-bit untouched. Audit/legal provenance preserved.


[ STAGE 3: CANONICAL DUAL-VIEW TABLE & PROPOSITION PACKER ]
--------------------------------------------------------------------------------
• Replaces: Naive table row slicing and EnSI-RAG's 468-second LLM table extraction.
• Input: Raw ASCII/Markdown table text + preceding lead-in banner.
• Deterministic Mechanisms:
    1. Unit Multiplier Banner Extraction:
       - Scans preceding 2 sentences for currency/unit patterns: "$ USD Millions", "% Defect Rate".
    2. Contiguous Block Packing [r : r+k]:
       - Packs contiguous rows into chunks to preserve accounting flow (Revenue - Expense = Profit).
    3. Dual-View Representation:
       - View 1: Markdown grid with replicated column headers + alignment row + unit banner.
       - View 2: Compact linearized cell propositions (Metric: Col1=Val1, Col2=Val2).
• Output Contract:
    - Table Chunk Sequence: List[TableChunk(markdown_view, proposition_view, token_count <= 512)].
• Invariant: 100% header/schema inheritance; strict knapsack budget <= 512 tokens.


[ STAGE 4: DETERMINISTIC ENTITY-STRUCTURE HANDLE INDEX & BIPARTITE GRAPH ]
--------------------------------------------------------------------------------
• Replaces: CROSSAUG's 5.7h GNN+LLM edge extraction and EnSI-RAG's LLM tuple extractor.
• Input: Chunks from Stage 2 (Prose) and Stage 3 (Tables).
• Deterministic Mechanisms:
    1. Structured Handle Emission matching EnSI-RAG's schema:
           [e][t][c : k = v] -> {chunk_id}
       where c \in {property, relation, aspect}.
       - From Tables: [Helios Semiconductor][ORG][property : Operating Income (Q3 2026) = -$158.20M] -> {chunk_5}
       - From Prose:  [Meridian Vault IP Holdings LLC][ORG][relation : licensed = Kronos-7] -> {chunk_10}
       - From Cites:  [Section 4.2][CLAUSE][relation : cites = Section 4.1] -> {chunk_12, chunk_8}
    2. Bipartite Entity-Chunk Graph G = (V_entities \cup V_chunks, E):
       - Edges represent deterministic membership and explicit cross-references.
• Output Contract:
    - In-Memory Handle Inverted Index + Bipartite Graph Adjacency List.
• Invariant: O(1) symbolic lookup time; zero LLM indexing calls; zero hallucinated edges.


[ STAGE 5: DETERMINISTIC DUAL-AXIS RETRIEVAL & AUTO-MERGE ]
--------------------------------------------------------------------------------
• Replaces: SAKI-RAG's 20s Qwen-max filter and flat top-k concatenation.
• Input: Query string q, Inverted Index, Bipartite Graph, Vector Store.
• Deterministic Mechanisms at Query Time (<15 ms):
    1. Dual-Axis Retrieval:
       - Axis 1: Dense Vector Cosine Similarity via Qwen3-Embedding-0.6B (Mean-Pooled centroid).
       - Axis 2: Deterministic Handle Matching ([e][t][k] exact match bonus + date match bonus).
    2. Deterministic Graph Bridge Expansion:
       - Automatically retrieves target chunk for explicit citation pointers (Section X.Y, Footnote N).
    3. HiChunk Deterministic Auto-Merge:
       - Iteratively evaluates candidate chunks under common AST parent p:
         (Cond 1 - Coherence):     |\mathcal{N} \cap children(p)| >= 2
         (Cond 2 - Substantiality): \sum_{n \in \mathcal{N} \cap children(p)} len(n) >= \theta^*(T_used, p) * len(p)
                                    where \theta^*(T_used, p) = (1/3) * (1 + T_used / T_max)
         (Cond 3 - Feasibility):    T_used + len(p) <= T_max
• Output Contract:
    - Merged, semantically cohesive parent/child context package ready for generation.
• Invariant: Zero fragment dilution; guaranteed token budget compliance (<= T_max).
